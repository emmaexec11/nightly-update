## HOW TO USE EVERYTHING:

### GOALS:
1. **Click Goal Title** → Edit the goal name
2. **Click 🎨 Icon** → Change goal color  
3. **Click Any Period Box (Yearly/Quarterly/Monthly/Weekly)** → Opens editor with:
   - Notes section
   - Links (add multiple URLs)
   - Lead Indicators (what you'll DO)
   - Lag Indicators (what you'll MEASURE)
   - Shows 📝 icon when period has data

### HABITS:
1. **Click "+ Add Habit"** → Create new habit
2. **Click Habit Name** → Opens full detail modal with:
   - 30-day calendar with three colors:
     - 🟣 Purple = Days you don't need to do it
     - 🔴 Red = Scheduled days you missed
     - 🟢 Green = Days you completed it
   - Success rate percentage
   - Current streak
   - Frequency settings (daily/weekdays/weekends/etc)
   - Notes section for steps/details
3. **Click Checkbox** → Mark today complete
4. **Click 📝 Button** → Add/edit notes
5. **Click × Button** → Delete habit

### CALENDAR BEHAVIOR:
- Purple days → Click to mark as "bonus" completion
- Red days → Click to mark complete (turns green)
- Green days → Click to mark incomplete (turns red if scheduled)
- Frequency setting controls which days are purple
