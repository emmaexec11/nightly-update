Version 4.10 - UI Improvements
==============================

## Changes Made:

1. **Auth Buttons Now Subtle** 
   - Changed from blue buttons to subtle 🔒 lock icons
   - Low opacity (0.5) to stay hidden
   - Only visible when you need them

2. **Calendar Shows 3 Days**
   - Removed the Expand/Collapse button
   - Always shows "Next 3 Days"
   - No more toggling between tomorrow/week view

3. **Task Checkboxes**
   - Replaced green checkmark button with standard checkbox
   - Unchecked by default
   - Check to delete the task
   - If deletion fails, checkbox unchecks itself

## Note:
You still need to re-authenticate for the delete functionality to work (need write permissions).
