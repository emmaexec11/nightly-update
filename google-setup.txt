Google API Setup Instructions
=============================

To connect your Google Calendar and Tasks to the nightly update dashboard, you need to provide the same credentials used in your morning dashboard.

OPTION 1: Get from Morning Dashboard Code
-----------------------------------------
1. Open your morning dashboard HTML file
2. Search for "client_secret" to find: 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
3. Search for "refresh_token" to find the long token starting with "1//06..."

OPTION 2: Get from Browser Storage
-----------------------------------
1. Go to your morning dashboard
2. Open DevTools (F12)
3. Go to Application tab
4. Check localStorage or sessionStorage for:
   - google_client_secret
   - google_refresh_token

WHEN PROMPTED:
--------------
1. Click "Configure Google API" button
2. Enter the client secret when prompted
3. Enter the refresh token when prompted
4. The dashboard will save these securely in your browser

The credentials are stored locally in your browser and never sent anywhere except to Google's official OAuth servers.
